# 🚀 Day 16 Mini Project — Laundry Order Processor

Build a small program that simulates processing a customer's laundry order.

Your program should:

1. Receive a customer's name.
2. Display that the order has been received.
3. Pass control to another function that processes the laundry.
4. After processing, pass control to another function that completes the order.
5. Display a final message when the order is complete.

Your program should produce something similar to:

```text
========================
KLASSY KLEAN
========================
Customer: Godwin
Order received.
Laundry processing...
Laundry complete.
Order ready for pickup!
```

**Rules:**

* You must create at least **3 functions**.
* At least one function must accept a **callback**.
* You must pass functions as arguments.
* Don't copy a solution from the lesson.
* You decide the function names and how the functions communicate.


This is especially important as we move toward **Promises, Async/Await, APIs, Node/Express, React, and the final Laundry System**.
