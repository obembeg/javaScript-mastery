# Exercises

## Exercise 1 — Successful Promise

Create a Promise that resolves with:

```text
Order completed successfully!
```

Then print the message using `.then()`.

---

## Exercise 2 — Failed Promise

Create a Promise that rejects with:

```text
Order failed!
```

Handle it using `.catch()`.

---

## Exercise 3 — Laundry Promise

Create:

```javascript
const laundryCompleted = true;
```

Create a Promise.

If `laundryCompleted` is `true`:

```text
Laundry is ready!
```

Otherwise:

```text
Laundry processing failed.
```

Handle both cases.

---

## Exercise 4 — Delayed Promise

Create a Promise that waits **2 seconds** using `setTimeout()`.

Then resolve with:

```text
Laundry is ready for pickup!
```
